Uses

Orange Antelight can be used as decoration and also emanates an orange light around it.

Sources

Orange Antelight can only be obtained through planting an Orange Antelight Seed.

Notes

  • A planted Orange Antelight can only be harvested once. When fully grown, the Antelight is removed entirely from the plot, so another one has to be planted to produce a new Orange Antelight.
